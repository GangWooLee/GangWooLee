# 이강우

연세대학교 컴퓨터과학과에 재학 중이며 2028년 2월 졸업 예정입니다.
업무 하나를 놓고 AI가 처리할 단계와 사람이 확인할 단계를 나눈 뒤, 그 구분대로 동작하는 시제품을 만들어 왔습니다.

2026년 7월부터 도움AI에서 FDE(Forward Deployed Engineer)로 일하며 병원 고객의 요구사항을 정리하고 구현 결과를 QA합니다. 고객 작업은 비공개라서 이 계정에는 개인 프로젝트와 팀 프로젝트만 있습니다.

## 대표 프로젝트

- [COOA](https://github.com/GangWooLee/cooa-web): 화장품 수출 도안을 국가별 규제 기준으로 사전검토하고, 수정 요청과 검토 상태를 도안 버전별로 관리하는 웹 앱입니다. 도안 편집은 디자이너가 쓰던 도구에 남기고 검토 기록만 다루도록 범위를 좁혔습니다.
- [모듈형 보험 리스크 예측](https://github.com/GangWooLee/insurance_model_agent): 보험 리스크를 6개 독립 모듈로 예측하고, 심사 단계에 맞춰 설명을 생성하는 시제품입니다. 제가 설계한 설명 에이전트는 점수를 바꾸지 못합니다. 점수와 기여값은 코드가 계산하고 LLM은 그 기록을 읽어 서술하며, 가입자용 설명은 심사역의 최종 판단 뒤에 만들어집니다.
- [Engineering Ownership](https://github.com/GangWooLee/engineering-ownership): AI 코딩 도구가 만든 변경의 결정 이유와 검증 결과를 저장소에 남기는 도구입니다. 시험 결과를 현재 diff에 묶어서, 이전에 통과한 결과로는 지금 변경을 통과시킬 수 없습니다. 이 저장소도 같은 방식으로 관리해 결정 기록 20건이 `docs/engineering`에 있습니다.
- [KeyBox](https://github.com/GangWooLee/key_box): 네트워크 권한 없이 동작하는 macOS 비밀 관리 앱입니다. 위협 모델 문서에 공격 경로 33개와 각각을 막았는지, 감수했는지, 아직 못 막았는지를 적었습니다.

구현에는 Claude Code와 Codex를 씁니다. 보험 리스크 예측 README에는 AI가 작성한 부분과 제가 판단한 부분을 나눠 적었습니다.
